# 📊 Análise de Cancelamento de Clientes (Churn Analysis)

## 📌 Sobre o Projeto

Este projeto tem como objetivo analisar os fatores que influenciam o cancelamento de clientes de uma empresa.

A análise foi desenvolvida utilizando Python e bibliotecas de análise de dados, com foco em identificar padrões de comportamento relacionados ao churn (cancelamento).

---

## 🎯 Objetivo

Identificar os principais motivos que levam clientes a cancelarem seus serviços e gerar insights que possam ajudar a empresa a reduzir o churn.

---

## 🛠 Tecnologias Utilizadas

- Python
- Pandas
- Plotly
- Jupyter Notebook

---

## 📂 Etapas do Projeto

### 1. Importação da Base de Dados
Leitura do arquivo CSV contendo os dados dos clientes.

### 2. Limpeza e Tratamento
- Remoção de valores vazios
- Ajuste de colunas
- Padronização dos dados

### 3. Análise Exploratória
Análise visual e estatística das variáveis que impactam o cancelamento.

### 4. Visualização de Dados
Criação de gráficos interativos utilizando Plotly.

---

## 📈 Principais Insights

✅ Clientes com contrato mensal possuem maior taxa de cancelamento.

✅ Clientes com maior número de ligações ao call center tendem a cancelar mais.

✅ O comportamento do cliente influencia diretamente o churn.

---

## 🚀 Possíveis Soluções para a Empresa

- Incentivar planos anuais
- Melhorar atendimento ao cliente
- Reduzir problemas que geram excesso de chamadas
- Criar campanhas de retenção
